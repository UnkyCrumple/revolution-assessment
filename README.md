# Impact Lab: The American Revolution

A single-file interactive learning activity and assessment for a freshman U.S. History I unit (Utah Core Strand 3, standards 3.1–3.4).

- Four sections, one per standard, with 19 stops in total.
- Students pick one stop per section (or use the random pick button) and write one CER (claim, evidence, reasoning) for it.
- Plan for two class days: Sections 1–2 on Day 1 and Sections 3–4 on Day 2, each day followed by a 20-minute debrief.
- Every stop lists its numbered sources.

## Use

Open `index.html` in a browser. It has no dependencies and works offline. Student work is saved in that browser only.

## Teacher access

Sections 3 and 4 are open to students. Section 2 opens after Section 1 is finished, and Section 4 opens after Section 3 is finished.

Use the small **Teacher** link at the bottom of any page and enter a code:

- `TEACH` turns on teacher notes and opens everything.
- `STUDENT` turns teacher view off.

These codes are visible in the page source, so they are not security.
